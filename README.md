# 红果 TV

**把好故事，留给大屏。** 为遥控器设计的 Android 电视短剧客户端。

[下载正式版 · Cloudflare](https://tv-admin.curatedlifefinds.com/download) · [GitHub Releases 备用下载](https://github.com/ljl215186/hongguoTV-updates/releases) · [反馈问题](https://github.com/ljl215186/hongguoTV-updates/issues)

Android 8.0 及以上 · 全屏推荐 · 短剧 / 漫剧 · 全库搜索 · 收藏与续播

## 电视上的观看方式

- **推荐**：有声预览，上下切换作品，OK 看全集；返回唤出透明导航。
- **找剧**：多个排行榜、真人剧 / 漫剧筛选、关键词全库搜索；支持系统语音或电视输入法。
- **我的**：接着看、收藏、稍后看，记录保存在本机。
- **设置**：清晰度、倍速、画面适配、备份恢复、应用更新。
- **打赏与交流**：同页分组展示，内容由运营后台维护。

## 安装与更新

1. 从上方下载页下载带版本号的 APK，传入电视，通过系统文件管理器安装。
2. 首次安装可能需要允许“安装未知来源应用”，随后确认系统安装。
3. 正式版内打开 **设置 → 版本与更新** 可检查、下载并安装新版。也会在前台空闲时自动检查，播放中不打扰。
4. 关闭自动下载仍可收到必要更新提示。安装必须由用户确认，不会静默安装。

**旧版首次迁移**：正式包名为 `com.ljl215186.hongguotv`，使用独立数据目录，可与旧应用并存。先在旧版 **设置 → 手机备份与恢复** 导出并保管 JSON；安装正式版后从同一入口导入，勾选恢复播放设置并确认记录正确。旧应用可继续保留。后续正式版可直接覆盖升级。

广告默认由后台关闭。启用后可按权重选择自营图片、视频或网页，达到展示条件后按 **↓ 下一集**，按返回退出观看。第三方广告来源需单独完成 SDK 与电视交互验收才会开放生产展示。
